# StressPunch · 把照片变成沙包

> 上传一张脸，把它贴到 3D 沙包上，然后尽情出拳。

在浏览器里打开就能玩，不用注册、不用下载、不用安装。

**直接开玩 → <https://jasonsun2009cn.github.io/StressPunch/>**

## 这是什么

一个用来泄压的小玩具。

- 把任意照片（JPG / PNG / WebP）贴到弧形沙包正面，沙包会实时摆动、回弹、被压扁。
- 手写物理 + 合成音效 + 拳印、火星、屏幕震动，出拳有手感。
- 电脑和手机都能玩，鼠标、触摸、键盘都支持。

## 三步开始

1. 打开上面的链接。
2. 选一种模式，再选一张照片（不选也能玩，沙包上会有占位图案）。
3. 点「进入擂台」，开打。

## 怎么出拳

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 刺拳 | 点击沙包 | 轻点沙包 |
| 勾拳 / 上勾拳 | 快速拖动 | 快速滑动 |
| 连续出拳 | 按住 | 按住 |
| 键盘出拳 | `J` 轻 · `K` 中 · `Space` 重 | — |
| 暂停 | `Esc` | 左上角暂停按钮 |

## 四种模式

| 模式 | 玩法 | 适合 |
| --- | --- | --- |
| **Zen** | 没有时间，没有分数，只有出拳 | 放空、单纯发泄 |
| **Time Attack** | 30 / 60 / 120 秒内拿尽可能多的分 | 想冲个高分 |
| **Combo** | 连击不能断，断一次就结算 | 追求手感与节奏 |
| **Precision** | 打中移动靶心加分，打偏扣分 | 想认真较劲 |

分数只存在你自己的浏览器里，各模式分别记录个人最佳。

## 你的照片不会离开这台设备

- 照片在浏览器本地读取、本地绘制，**不会上传到任何服务器**。
- 也不会写进 `localStorage` 或 IndexedDB，刷新页面后就没了。
- 本地只保存语言、静音、回合时长这类设置和最高分。

## 小提示

- 用本地的全身照或自拍效果最好；照片会自动裁切。
- 打开声音体验更完整（首次点击后才会启用音频）。
- 手机竖屏也能玩，横屏视野更宽。
- 建议用较新的 Chrome、Edge、Safari 或 Firefox，需要支持 WebGL。
