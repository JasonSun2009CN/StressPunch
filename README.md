# StressPunch

把你的照片贴到 3D 沙包上，然后尽情出拳。纯前端单页应用，无需后端、账号或构建工具，照片只在浏览器本地处理。

> 只想玩，不想看代码？看 [`docs/README.md`](docs/README.md) —— 一页纸的玩家指南。

## 功能

- **照片 → 3D 沙包**：上传任意 JPG / PNG / WebP，自动裁剪并贴到弧形沙包正面。
  - `全身`：方形 cover 裁切，适合人像/半身照。
  - `头像`：圆形裁切 + 海报式排版，适合自拍。
  - 没有照片时显示占位图案，照样能玩。
- **手写物理**：双轴钟摆弹簧 + 挤压弹簧，固定 1/120s 子步进，无 cannon-es / ammo。
- **打击反馈**：挥摆、回弹、挤压、火星粒子、屏幕震动、3 秒渐隐拳印、连击浮字、屏幕闪光。
- **四种模式**：Zen / Time Attack / Combo / Precision。
- **合成音效**：WebAudio 实时合成拳击、UI、回合结束音，无音频文件；仅在首次用户手势后解锁。
- **中英双语**：默认跟随浏览器语言，可随时切换并记住选择。
- **本地记录**：设置与各模式个人最佳存入 `localStorage`。
- **响应式**：桌面双栏、手机单栏；横竖屏均可玩。

## 运行

项目是纯静态站点，但使用了 ES Modules，必须通过 HTTP 访问（不能直接双击 `index.html`）。

```bash
# 方式一：Python
python3 -m http.server 4173

# 方式二：Node
npx serve .
```

然后打开 `http://localhost:4173`。

### 部署

把仓库根目录整个上传到任意静态托管即可，无需构建：

- GitHub Pages
- Netlify / Vercel（Build command 留空，Publish directory 为 `/`）
- Cloudflare Pages
- 任意 Nginx / S3 + CDN

### 外部依赖

- Three.js `0.160.1`，通过 `index.html` 中的 import map 从 jsDelivr 加载。
- Google Fonts（Barlow Condensed / Inter）。

离线或内网部署时，可将 Three.js 下载到 `vendor/three.module.js`，并把 import map 改为本地路径；字体可移除或自托管。

## 操作

| 操作 | 桌面 | 手机 |
| --- | --- | --- |
| 刺拳 | 点击沙包 | 轻点沙包 |
| 勾拳 / 上勾拳 | 快速拖动 | 快速滑动 |
| 连续出拳 | 按住 | 按住 |
| 瞄准 | 鼠标位置 | 手指位置 |
| 键盘出拳 | `J` 轻 / `K` 中 / `Space` 重 | — |
| 键盘瞄准 | `←` `→` `↑` `↓` | — |
| 暂停 / 继续 | `Esc` | 左上角暂停按钮 |

暂停菜单里可以继续、重开、结束回合（Zen 以外）或返回主菜单。

## 模式

| 模式 | 规则 | 计时 | 计分 |
| --- | --- | --- | --- |
| **Zen** | 没有时间与分数，纯出拳 | 无 | 否 |
| **Time Attack** | 30 / 60 / 120 秒内尽可能多拿分 | 倒计时 | 是 |
| **Combo** | 连击窗口 1.2 秒，断连立即结算 | 无 | 是 |
| **Precision** | 击中移动靶心拿高分，打偏扣分 | 无（暂停菜单手动结束） | 是 |

### 计分规则

- 基础分：`10 × 力度`（力度 0.3–1.5）。
- 连击倍率：每 5 连击 +0.5，最高 5×。
- 精准模式：命中靶心系数 2.0，靶环边缘约 0.5；未命中靶心扣 5 分且断连。
- 连击窗口：`1.2s`；暂停会冻结连击倒计时。
- 各计分模式的个人最佳单独保存。

## 隐私

- 照片通过浏览器 `File` / `createImageBitmap` 本地读取，绘制到 Canvas 后作为 `CanvasTexture` 贴到 3D 沙包。
- **照片不会上传，也不会写入 `localStorage` / IndexedDB**；刷新页面后需要重新选择。
- 仅保存非敏感设置与分数：
  - `stresspunch.settings`：语言、静音、照片贴法、回合时长、上次模式。
  - `stresspunch.best`：各计分模式最高分。
- 可在设置中一键清除个人最佳，或直接清除站点数据。

## 性能

- 物理固定步长 `1/120s`，单帧最多 6 个子步，避免掉帧后爆炸。
- 粒子池 300、拳印池 20，全部复用，不逐帧创建对象。
- 渲染像素比：桌面上限 2，手机上限 1.75；竖屏自动拉远相机。
- 阴影贴图 1024，仅主光投影；链节与吊盘不投影，减少无关阴影。
- 目标 60fps；低端设备会优先保证物理与输入响应。

## 项目结构

```
index.html          页面结构、import map、HUD / 菜单 / 结果 / 设置
styles.css          全部样式与响应式规则
src/
  main.js           状态机、回合流程、计分衔接、照片读取
  scene.js          Three.js 渲染器、相机、灯光、地面、震屏
  bag.js            沙包几何、照片贴图合成、形变应用
  physics.js        钟摆 + 挤压弹簧
  input.js          鼠标 / 触摸 / 键盘统一输入与射线检测
  effects.js        粒子、拳印、浮字、闪光
  audio.js          WebAudio 合成音效
  modes.js          模式配置、靶心、格式化
  score.js          localStorage、连击与计分
  ui.js             DOM 绑定与视图状态
  i18n.js           中英文字典
```

调试时可在控制台访问 `window.stressPunch`（应用实例）查看状态、分数与物理参数。

## 已知限制

- 照片只做自动 `cover` 裁切，暂不支持手动平移 / 缩放取景。
- 没有在线排行榜，分数只存在本机。
- Precision 模式不设倒计时，需要在暂停菜单里手动结束。
- 依赖 CDN 加载 Three.js 与字体；完全离线部署需按上文自托管。
